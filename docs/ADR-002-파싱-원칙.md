# ADR-002 — 파싱 원칙 3종 (실측으로 뒤집힌 것들)

- **상태**: 채택
- **일자**: 2026-08-12
- **범위**: Recognition · 파서 4종 · Normalization. **세션 2 이후에도 구속한다.**

세 가지 모두 처음에 반대로 구현했다가 픽스처 실측에서 깨졌다. 코드 주석은 리팩터링에 쓸려나가므로 여기에 남긴다.

---

## 1. 엑셀 날짜는 UTC 게터로 읽는다

SheetJS는 `cellDates: true`일 때 셀의 시리얼 번호를 **UTC 자정**으로 실체화한다. 픽스처 #11의 2026-07-01 셀(시리얼 46204)은 `.v === 2026-07-01T00:00:00.000Z`다.

```ts
// 맞다 — 실행 환경의 타임존과 무관하게 달력 날짜가 나온다
`${d.getUTCFullYear()}-${pad(d.getUTCMonth() + 1)}-${pad(d.getUTCDate())}`

// 틀렸다 — KST에서 09:00이 붙고, UTC보다 서쪽에서는 전날로 밀린다
`${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`
```

**왜 헷갈렸나.** `sheet_to_json`을 거치면 값이 한 번 더 변환돼 로컬 자정처럼 보인다. 우리는 `!data`의 셀을 직접 읽으므로 그 변환을 거치지 않는다. 탐색 단계에서 `sheet_to_json`으로 확인하고 구현은 직접 읽는 경로로 하면서 어긋났다.

**왜 중요한가.** 엑셀의 날짜에는 타임존이 없다. 정산 날짜가 하루 밀리면 월 경계에서 매출이 다른 달로 넘어가고, 그건 조용히 틀린 숫자의 전형이다(헌장 A-5). 서버가 없는 로컬 앱이라 사용자 기기의 타임존이 곧 실행 환경이고, 그 값이 판정에 섞이면 안 된다.

**지킴장치.** `dateToRaw`의 테스트가 `2026-07-01T00:00:00.000Z`를 넣고 `"2026-07-01"`을 요구한다. 로컬 게터로 되돌리면 KST에서 즉시 깨진다.

## 2. 파일에 타입 체계가 있으면 따르고, 없으면 우리가 정한다

| 포맷 | 셀 타입 | 읽는 방식 |
|---|---|---|
| xlsx · BIFF | 파일이 갖고 있다 (`t="s"` · `t="n"` · 날짜 서식) | **파일을 따른다.** 숫자는 숫자로, 날짜는 날짜로 받는다 |
| HTML 표 · 구분자 텍스트 | 없다. 전부 텍스트다 | **우리가 정한다.** `raw: true`로 원문을 받아 Normalization이 판정한다 |

**왜.** SheetJS는 HTML 표를 읽을 때 타입을 추론해서 `"753,100"`을 숫자 `753100`으로, `"2025-10-01"`을 시리얼 `45931`로 바꿔놓는다. 그러면 두 가지가 깨진다:

1. **원본이 사라진다.** `NormalizedValue.raw`가 보존해야 할 값이 이미 변환된 뒤다. 조정 레이어(헌장 B-3)는 "원본 + 조정"으로 유효값을 만드는데, 그 원본이 우리가 못 본 값이 된다.
2. **규칙이 두 겹이 된다.** `"3,000원"`·`"12.4%"`·`"-"` 같은 한국 마켓 표기는 SheetJS의 추론 대상이 아니다. 절반은 SheetJS가, 절반은 우리가 바꾸면 어느 규칙이 적용됐는지 값만 봐서는 알 수 없다.

**따름 규칙.** 새 파서를 추가할 때 그 포맷에 셀 타입이 있는지 먼저 판단한다. 없으면 원문 문자열을 그대로 Normalization에 넘긴다.

## 3. "확장자와 다르다"는 한 가지가 아니다

`extensionMismatch` 불리언 하나로는 부족하다. 픽스처가 세 가지 다른 어긋남을 보여준다:

| 픽스처 | 이름 | 실제 | 어긋난 층 |
|---|---|---|---|
| #12 | `.xls` | HTML 표 | **컨테이너 포맷** |
| #1 · #2 | `.csv` | TAB 구분 | **구분자** — 포맷은 `delimited`로 일치한다 |
| #1 · #2 | `.csv` | UTF-16 LE | **인코딩** |

`extensionMismatch`는 #12만 잡는다. #1·#2는 컨테이너가 `delimited`로 맞아떨어져 불리언이 `false`가 되지만, 다른 도구로 열면 한 컬럼으로 뭉개지는 파일이다.

그래서 `RecognitionResult`는 두 가지를 함께 낸다:

```ts
extensionMismatch: boolean          // 컨테이너 포맷이 다르다
identityNotes: readonly string[]    // 사람에게 할 말 — 포맷·구분자·인코딩 중 다른 것만
```

**따름 규칙.** 헌장 C-5의 "파일 정체 고지"는 `identityNotes`를 쓴다. 어긋난 게 없으면 빈 배열이다 — 정상 파일에까지 배너를 띄우면 배너가 무의미해진다.

## 재검토 트리거

1. SheetJS 메이저 업그레이드 → 날짜 실체화 기준이 바뀌었는지 #11로 재확인
2. 셀 타입을 갖는 새 텍스트 포맷 도입 → 2번 표에 행 추가
3. 확장자와 어긋나는 새 층 발견(예: 압축 방식) → `identityNotes`에 항목 추가
