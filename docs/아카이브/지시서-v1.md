## 0. 제품 정의 (LOCK)

- **제품명(가칭)**: FlowBase 손익
- **한 줄**: 마켓 정산서를 던지면 진짜 손익이 나오는 셀러용 로컬 앱.
- **타겟**: 한국 오픈마켓 3~5채널 운영 솔로/소규모 셀러.
- **핵심 철학**: AI가 초안(매핑·분류)을 만들고, 사람이 확정한다. 자동 적용 없음.
- **포지셔닝 문장** (온보딩·랜딩에 사용): "가입 없음. 데이터는 당신 컴퓨터 밖으로 나가지 않습니다."

## 1. 확정 아키텍처 결정 — 디자인에 영향을 주는 것만 (LOCK)

| 결정 | 디자인 함의 |
|---|---|
| 로컬퍼스트 (Tauri + SQLite, 서버 없음) | 로그인/가입 화면 **없음**. 클라우드 아이콘·"저장 중..." 스피너 없음 (저장은 즉시·로컬) |
| v1 = 파일 가져오기 중심, API 연동은 v1.5 | 연결 화면에서 API는 "지원 예정" 상태 표기 가능. XLSX/CSV 업로드가 주 동선 |
| 자격증명 로컬 암호화 (vault://) | 기존 목업의 vault:// 참조 표기 유지. "이 키는 이 컴퓨터에만 저장됩니다" 문구 추가 |
| 양식(필드 매핑) = 코드가 아닌 데이터, 원격 업데이트 | 양식 업데이트 배너 UI 필요 (신규 화면 §3-C) |
| 깨질 때 곱게 깨진다 | 매핑 신뢰도 강등 상태 UI 필요 (신규 화면 §3-D). 오염된 숫자를 손익에 반영하지 않음 |
| 결제 = Lemon Squeezy 외부 링크 + 라이선스 키 | 앱 내 결제 화면 없음. 설정에 라이선스 키 입력 (신규 §3-B) |

## 3. 신규 화면 4개 — 이번 작업의 핵심

### 3-A. 페이월 / 업그레이드 모달
- 트리거: 무료 유저가 2번째 채널 추가 시도, 또는 잠금 배지 클릭.
- 내용: 무료 vs Pro 비교 2컬럼 + "무료로 계속" 탈출구 항상 제공 (다크패턴 ❌).
- CTA: "Pro 시작하기" → 외부 결제 페이지로 나간다는 표시 (↗ 아이콘).
- 잠긴 채널 카드: 기존 연결 화면의 채널 카드에 자물쇠 배지 변형 추가.
- 톤: 위협·긴급성 카피 금지. "채널을 더 붙일수록 손익이 정확해집니다" 방향.

### 3-B. 설정 > 라이선스
- 위치: 기존 settings 뷰에 섹션 추가.
- 요소: 라이선스 키 입력칸(모노스페이스) · 활성화 버튼 · 상태 표시 3종(미입력/활성/만료) · "키 구매하기 ↗" 링크.
- 활성 상태: 플랜명 + 다음 갱신일 표시. 해지 안내는 "결제 페이지에서 관리 ↗" 한 줄.
- 로그인·이메일 입력 요소 일절 없음.

### 3-C. 양식 업데이트 배너
- 위치: 해당 채널 데이터 화면 상단 + 필드매핑(fieldmap) 뷰 해당 양식 카드.
- 카피 예: "쿠팡 정산 양식이 v2026-09로 업데이트되었습니다 — 변경 2건"
- 액션: [변경 내용 보기] [적용] — 적용 전 diff 미리보기 (기존 매핑 vs 새 매핑, 바뀐 행만 하이라이트).
- 원칙: 자동 적용 ❌. 사람이 확정 버튼을 누른다. (제품 철학 그대로)

### 3-D. 매핑 신뢰도 강등 상태 (양식 깨짐)
- 트리거: 가져온 파일이 기존 양식과 안 맞을 때.
- 채널/양식 카드에 경고 상태: "정산 양식이 바뀐 것 같습니다 — 확인 필요"
- 해당 기간 손익 숫자에 "미확정 데이터 제외됨" 표시 (조용히 틀린 숫자 ❌).
- 복구 동선: [AI로 다시 매핑] → 기존 목업의 필드매핑 확정 UI 재사용 (컬럼별 근거 + lv 0/1/2 신뢰도 그대로).
- 기존 STATES 6종(CONNECTED/SYNCING/ERROR/EXPIRED/REAUTH_REQUIRED/DISCONNECTED)에 **FORMAT_CHANGED(양식 변경 감지, yellow 계열)** 추가.

## 4. 기존 화면 수정 사항

1. **동기화 표기 정직화**: "동기화 중 · 실시간" 류 연출 제거. → "마지막 가져오기: 오늘 20:41" / "다음 실행 시 확인". SYNCING 상태는 가져오기 진행 중일 때만.
2. **온보딩(첫 실행)**: 빈 대시보드 대신 정산서 드롭존이 첫 화면. 3단계: ① 파일 드롭 → ② AI 매핑 초안 + 사람 확정 → ③ 손익 대시보드. "데이터는 로컬에만 저장됩니다" 문구 1단계에 명시.
3. **connect 뷰**: API 연동 카드에 "v1.5 지원 예정" 상태 추가. 파일 업로드 경로를 첫 번째 옵션으로 승격.
4. **design(데이터 구조) 뷰**: 유지하되 내비 하단으로 이동 (일반 유저 대상 아님, 파워유저용).

## 5. 유지 (변경 금지)

- 다크 기본 톤 · --pnl-* / --label-* 토큰 체계 · 손으로 그린 SVG 차트 13종
- 필드매핑의 컬럼별 근거("정산금액의 약 12%") + 신뢰도 lv 표기 — 이 제품의 시그니처
- 원가 이력 · 광고비 배분 룰 · 운영비/고정비 분리 · Adjustment Layer UI
- 13뷰 내비 구조 (design 위치 이동 외)
- 한국어 카피의 현재 톤 (건조·구체·숫자 중심)

## 6. Out of Scope — v1 목업에 그리지 않는 것

- 로그인/가입/소셜 로그인 (v2 동기화 계정 때)
- 협업·멤버·권한 UI
- 모바일 레이아웃 (반응형 축소는 현재 수준 유지, 전용 설계는 후속)
- 실시간 동기화 연출
- 앱 내 결제 플로우 (외부 링크로 충분)
- 재고·CS 등 다른 팩의 흔적

## 7. 산출물 요구

- 기존 목업 파일에 통합 (별도 파일 ❌) — startView prop에 신규 화면 진입점 추가.
- 신규 화면 4개는 실데이터 흐름이 보이게: 페이월은 무료 유저 상태에서, 3-C/D는 쿠팡 채널에 시연 데이터로.
- 상태별 변형이 있는 요소(라이선스 3종, FORMAT_CHANGED)는 전환 가능하게 (기존 preview 토글 패턴 재사용).
