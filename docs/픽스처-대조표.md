# 픽스처 15종 — 독립 대조표 (expected 매니페스트 검증용)

> 작성: 설계 대화의 Claude (Claude Code와 **다른 도구**로 실측: openpyxl / xlrd / 바이트 검사 / utf-16 디코드).
> 용도: Claude Code가 자기 파서로 뽑은 `expected*` 매니페스트와 **교차 대조**한다. 두 측정이 일치하면 통과,
> 불일치 항목만 사람이 판정한다 (파서 버그 또는 이 표의 오류, 둘 중 하나).
>
> **행 수 정의 주의.** 이 표의 행 수는 시트의 **물리적 최대 행**(헤더·제목·합계 포함) 기준이다.
> 파서의 "데이터 행 수"와 정의가 다를 수 있으므로, 불일치 시 **정의 차이인지 먼저 확인한다.**
>
> ⚠️ 통합 대시보드 등 일부 시트의 `max_row`(1000·1001·3000 등)는 서식만 있는 빈 행을 포함한 값일 수 있다 —
> 실데이터 행수와 다르면 "빈 행 트레일링" 여부를 확인.

## Normalization 정답 샘플

| 입력 | 기대 출력 | 출처 |
|---|---|---|
| `"0원"` | `0` | #9 |
| `"100.0%"` | `1.0` (또는 내부 percent) | #15 |
| `"-"` | `null` | #1·#11 |
| `""` (트레일링 생략) | `null` | #1·#2 ragged |
| `"2026-07-01 00:00"` 류 | date | #11 |
| `"20260804119"` | **identifier (문자열 유지 — 숫자 변환 금지)** | 주문번호 계열 |

## 함정 — expected 초안에서 빠지면 대조표가 잡아낸다

1. **#9·#10 시트명이 타임스탬프 포함이다** → 시트명 매칭에 의존 금지.
2. **#3의 라운드 숫자 행수(1000·3000)는 빈 행 트레일링** → `stopCondition` 검증에 쓸 것.
3. **주문번호는 숫자 변환 금지** → identifier로 문자열 유지. 엑셀이 이미 float로 만든 것을 파서가 또 망치면 안 된다.
4. **#8·#14는 실명 포함** → 비식별화 필수.
