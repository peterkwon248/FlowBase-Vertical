# 문서 지도

> ★ **이 파일은 대부분 «실측 주장(is)»이다 — 그래서 낡는다** ★
>
> 각 줄의 「무엇」은 **그 문서가 지금 무엇을 담고 있나**에 대한 주장이고,
> 쓰는 순간부터 낡기 시작한다(「구현됨」·「제안 · 확인 대기」·「결함 43건」).
> 그래서 **`CLAUDE.md`에서 여기로 내렸다** — 상시 로드되는 자리에 낡는 주장을
> 40줄 쌓아 두면 매 세션이 낡은 것부터 읽는다.
>
> `CLAUDE.md`에는 **규범(should)만** 남겼다. 규범은 안 낡는다.
>
> **의심되면 `ls docs/`와 각 문서의 첫 줄이 이 표를 이긴다.**

## LOCK ↔ 헌장 번호 별칭

### 규칙은 하나다 — 아래 LOCK 1~10이 정본

같은 규칙에 번호가 셋이었다(LOCK n · 헌장 B-n · 인계 2-n). **정본은 LOCK n이고**,
헌장의 B·C 번호는 그 문서 안의 절 번호로만 읽는다. 코드 주석의 옛 번호는 이 별칭표로 푼다:

*(헌장 원문을 한 줄씩 대조해 만들었다 — 짐작이 아니다)*

| LOCK | 헌장 | 무엇 |
|---|---|---|
| 1 | **B-1** | Fact 공통 6컬럼 |
| 2 | **B-2** | append-only · batch · UPSERT |
| 3 | **B-3** | 원본 불변 · 조정 스택 · 대사는 원본끼리 |
| 4 | **B-8** · E-4 | Core는 마켓을 모른다 |
| 5 | **A-2** · E-5 | 켤 때 전부 읽지 않는다 · 전체 메모리 적재 금지 |
| 6 | **A-5** · E-3 | 정직 원칙 = 조용한 실패 금지 |
| 7 | **A-4** · E-9 | AI는 액셀러레이터 — 꺼져도 전 기능 동작 |
| 8 | **B-10** · E-8 | 티어는 B-10이 전부 · 유료 잠금 추가 금지 |
